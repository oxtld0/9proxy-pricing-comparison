## 9proxy 卖的是什么：两套计费逻辑，不是两档会员

9proxy 只做住宅代理，但计费方式分两条线，这两条线的差别比你想象的更影响使用体验。

**按 IP 计费（Residential by IPs）**

买的是 IP 数量，不是流量。在 IP 存活期间流量不限。未使用的 IP 不会过期，按官方文档的描述，这属于“固定套餐”模式，你花过的钱不会因为日历翻页而作废。

**按 GB 计费（Residential by GB）**

买的是流量额度，端点数不限——同一个账号可以生成任意多的代理端点，系统只从流量池里扣 GB。这一套跑在网页 Dashboard 上，不需要装客户端，用用户名密码或 IP 白名单认证。IP 支持轮换模式和粘性会话模式。

两者的具体差异，官方文档给得比较明确：

| 对比项 | 按 IP | 按 GB |
| --- | --- | --- |
| 计费方式 | 按 IP 数量打包 | 按总流量打包 |
| 使用期限 | 不限，用完为止 | 最短 180 天，企业版不限 |
| IP 存活时间 | 几小时到约 24 小时（每个 IP 不同） | 每请求/每会话自动轮换 |
| 流量限制 | 活跃期间不限量 | 受购买的 GB 限制 |
| 端点数量 | 1 个 IP 转发时算 1 次使用 | 可无限生成 |
| 认证方式 | 需要 9Proxy 客户端（本地端口转发） | 用户名密码或 IP 白名单 |
| 技术门槛 | 必须装桌面客户端 | 直接在面板里跑 |

最后一行值得单独提醒：**按 IP 的方案必须装 Windows 客户端**，按 GB 的方案不需要。如果你是在服务器上跑自动化，或者不愿意在本地装东西，这一条基本就替你做完了选择。

## 按 IP 还是按 GB：看工作负载，不看单价

这是最容易选错的一步。选错的代价不是多花十几美元，而是买完之后发现根本用不上。

**按 IP 更适合：**
- 需要在一段时间内保持同一个 IP（多账号管理、登录态维持）
- 单个会话传输的数据量大，且流量难以预估
- 长期挂着的任务，不想每天盯流量余额

**按 GB 更适合：**
- 每个请求只拉几百 KB，但需要不停换 IP（轻量抓取、价格监控、广告验证、API 轮询）
- 需要按国家、州、城市甚至 ISP 精确定位（这些定位选项在 GB 方案里更完整）
- 用量不规则，希望额度能存半年而不是每月清零

简单算一下：如果你跑 5 万个请求、每个请求 300 KB，总流量大约 15 GB。按 GB 走，100 GB 套餐 $150 就跑完了，而且这 100 GB 能慢慢用到 180 天。换成按 IP 的方案，你买的是 IP 数量，跟请求量没关系——这种情况下按 IP 反而是浪费。

反过来，如果你要做 500 个社交账号的长期养号，每个账号需要一个稳定 IP，CPU 占用和流量都不是瓶颈，那按 IP 的 500 IP / $72 就比按 GB 划算得多，而且这些 IP 不会过期。

## 价格之外，几个必须先知道的限制

**每个 IP 的存活时间不固定。** 官方文档写的是几小时到约 24 小时，第三方测评提到平均寿命大约 3 小时。这是住宅代理的固有属性，不是 9proxy 独有的问题，但它会影响你的任务设计——需要长会话的任务得靠粘性模式或按 IP 方案。

**60 秒更换政策。** IP 激活后 60 秒内连不上，可以即时退回额度。超过 60 秒就不在覆盖范围内了。这条政策在行业里不常见，属于加分项，但它的边界很硬，第三方评价里针对退款条款的抱怨基本都集中在这里。

**Today List 免费复用。** 24 小时内取用过的 IP 可以免费再拿一次。测试阶段和会话提前结束时，这个功能能减少浪费。

**没有自助免费试用。** 官网上没有点一下就能拿的试用额度，第三方测评（Geekflare）也确认了这一点。想先测再买，需要联系客服申请，能否拿到取决于当期活动和库存情况。如果你习惯先白嫖小额度验证，这一点需要提前有心理准备。

**覆盖是 90+ 个国家，不是 195 个。** 池子里有 2,000 万+ 住宅 IP、8,000+ 台服务器，宣称 99.95% 可用率。第三方汇总的位置分布显示，美国、法国、加拿大、英国、德国的池子最深。跑美国、欧洲、东南亚的常见目标没问题；如果目标在很冷门的地区，先确认再下单。

**认证方式有区别。** 按 IP 必须用桌面客户端做本地端口转发，多设备使用会比浏览器插件麻烦；按 GB 可以直接在 Dashboard 里用账号密码或白名单。协议上 HTTP/HTTPS 和 SOCKS5 都支持，配合 anti-detect 浏览器、Scrapy、Puppeteer 这类工具不需要额外转换。

## 优惠和折扣实际是怎么运作的

9proxy 的促销用的是“不定期活动 + 券”的模式，而不是常年在页面上挂一个固定 promo code。已经结束的两场活动可以说明它的玩法：

- 2026 年 4 月的 Double Boost：完成当月第一笔 GB 订单后，系统自动往账户里发一张 9% 折扣券（格式 X9_xxxx），下次 GB 订单结算时自动套用。券只对 GB 订单有效，单次使用，4 月 30 日活动结束后不再发放。
- 2026 年农历新年：常规 IP 和 GB 套餐 8% 折扣，用码 LNY2026 在结算页手动输入，活动时间 1 月 23 日到 2 月 23 日。

两场活动都已经过去，写在这里不是让你去找这两个券，而是说明两个有用的事实：一是 9proxy 的折扣大多集中在 GB 订单上，组合套餐和 IP 套餐经常被排除在外；二是券不会自动续期，靠某篇文章里抄来的码去结算，大概率是无效的。真正有效的做法是在结算页看一眼当前有没有可用券，或者直接问客服当期有没有活动。

## 哪些人适合 9proxy，哪些人不适合

**适合：**

- 做多账号管理、需要固定住宅 IP 维持登录态的运营者
- 跑轻量抓取和广告验证，用量不规则、每请求数据量小
- 预算有限但需要真实的住宅 IP 质量
- 代理商和需要批量分配 IP 的团队（有批发价和转售方案）

**不太适合：**

- 只想跑几十个请求试试水的人——没有自助试用，最低门槛是 $15 的 5 GB 套餐
- 目标站点在冷门国家、需要 195 国全覆盖的场景
- 需要 Bright Data 那种企业级工具链和 SLA 的团队
- 完全不想碰桌面客户端的用户——如果只用按 IP 方案，客户端是绕不开的

## 常见问题

**9proxy 有免费试用吗？**
没有自助试用。试用额度需要通过客服申请，取决于当期活动。

**IP 和流量会过期吗？**
按 IP 套餐的未使用 IP 不会过期；按 GB 套餐的流量有效期为 180 天；企业版套餐的流量不设有效期。

**能退款吗？**
官方政策是 IP 激活后 60 秒内连接失败可即时返额。超过 60 秒的连接问题不在这一政策覆盖内，这也是用户评价里争议最多的部分。

**支持哪些协议和工具？**
HTTP/HTTPS 和 SOCKS5 都支持，可以配合主流 anti-detect 浏览器、代理链工具和 Python 脚本使用。

**IP 能定位到城市吗？**
GB 方案支持国家、州、城市、邮编和 ISP 级别的定位；按 IP 方案支持到州和城市级别。

**用哪个套餐起步比较稳？**
如果你的任务对 IP 稳定性要求高，从 100 IP / $24 起；如果是轮换型抓取，从 50+5 GB / $105 起比 5 GB 那档的单 GB 成本低 30%，更适合验证真实负载。

## 一句话总结

9proxy 的价格结构已经摆在上面了：IP 套餐买的是“不会过期的稳定 IP + 不限流量”，GB 套餐买的是“不限端点数 + 180 天有效的流量”。决定成本的不是单价数字，而是你的任务到底吃 IP 还是吃流量。选对模型，它在预算档位里是有竞争力的；选错模型，$126 和 $105 都可能打水漂。买之前确认目标站点在你需要的地区有没有足够的池子，买之后先用 Today List 和小额度把成功率验证一遍，再往大套餐上加钱。
